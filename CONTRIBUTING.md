# Contributing

Thanks for your interest in contributing to Sized!

## Setup

1. Fork the repo and clone your fork
2. Install dependencies: `pnpm install`
3. Start the dev server: `pnpm dev`

Requires Node.js 18+ and [pnpm](https://pnpm.io/).

## Making Changes

1. Create a branch from `main`
2. Make your changes
3. Run `pnpm lint` to check formatting and linting (uses [Biome](https://biomejs.dev/))
4. Run `pnpm build` to verify the build passes
5. Open a pull request against `main`

## Code Style

This project uses Biome for formatting and linting. Run `pnpm lint:fix` to auto-fix issues.

## Reporting Bugs

Open an [issue](https://github.com/YiftachCohen/sized/issues) with steps to reproduce the problem.
